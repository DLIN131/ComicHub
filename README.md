# ComicHub

把四個漫畫站整合成一個 Windows 桌面程式（Electron）。四個站在程式裡以 NH / JM / WN / EH 代稱。

## 下載

最新版：https://github.com/DLIN131/ComicHub/releases/latest/download/ComicHub-Windows.zip

解壓後執行 `ComicHub.exe`。之後有新版會在程式右下角提示，按「立即更新」就會自動下載、安裝並重新開啟（資料夾要有寫入權限，不要放在 Program Files）。

## 功能

- 首頁：四站最新更新，或切到單一站依排序瀏覽
- 搜尋：一次搜四個站（右上角 NH / JM / WN / EH 切換要搜哪幾站），結果交錯排列，每張封面標示來源網站
- 編號搜尋：純數字會用這個編號查每個勾選的站；加上站別前綴（例如 `JM123456`、`#123456`）只查該站；直接貼作品網址也可以（EH 只能用網址）
- 語言：上方「全部語言／中文／English／日本語」切換，首頁、搜尋、收藏、紀錄都會跟著篩，封面左下角標示語言
- 詳情：標籤點了會在所有勾選的站搜尋（原本的站用標籤精確搜尋）；多話作品有章節列表；「用此漫畫搜尋」可用書名、原文書名或作者到所有站找同一本
- 閱讀進度：自動記住每本看到第幾話、第幾頁，作品頁、書櫃有「繼續閱讀」，紀錄頁顯示看到哪
- 閱讀：直式捲動；↑ ↓ 像滑鼠滾輪一樣平滑捲動（按住一直捲），← → 換上一頁 / 下一頁（比畫面高的頁會先捲完再換頁），空白鍵 / PageDown 捲一個畫面，Home / End 跳到開頭 / 結尾，`+` / `-` 調整寬度，`Esc` 返回；被切條打亂的圖片會自動重組
- 下載：作品頁按「下載 CBZ」（多話作品可下載全部或單話），預設存到 ComicHub 程式資料夾裡的 `downloads`（舊版已經存在「下載\ComicHub」的會繼續用原本的位置），可改位置；CBZ 內附 ComicInfo.xml
- 書櫃（離線閱讀）：下載資料夾裡的 CBZ 會列在「書櫃」，不用網路就能閱讀；點漫畫開管理視窗，可閱讀、分組、點作者名搜尋相關作品、用書名搜尋、刪除；也可以用「開啟漫畫檔…」讀其他軟體做的 CBZ / ZIP。「建立合集」可以把幾本串成一本連續看，閱讀時上方選單能跳到每本的第一頁；合集可以加入新漫畫、拖曳調整順序、選一本當封面；在書櫃搜尋也找得到合集裡的書。連不上網站時首頁會提示改到書櫃
- 書櫃備份 / 還原：把觀看紀錄、閱讀進度、合集、分組、設定匯出成一個備份檔，電腦重灌後用「從備份檔還原」讀回來（漫畫檔要另外複製）
- 帳號：每個站各自登入（開該站自己的登入頁），登入後可看網站收藏。JM 的登入一陣子沒用會在網站那邊失效，登入時可以選擇讓程式記住密碼（Windows 加密存在本機），失效時自動重新登入
- 網站換網域時，在「帳號」頁改網址即可
- 不會把看過的圖片存成磁碟快取，看越多也不會越佔空間
- 觀看紀錄另外備份在 ComicHub 程式資料夾裡的 `backup`，AppData 被刪掉時會自動還原；程式資料夾不能寫入（例如裝在 Program Files）時改放 `%APPDATA%\ComicHub`

## 開發

```
npm install
npm start
```

F12 開發者工具、F11 全螢幕。`npm run pack` 打包到 `dist/ComicHub-win32-x64`。

推到 main 會由 GitHub Actions 自動打包並發布 `v1.0.<build 號>`。
